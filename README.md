# UNRC · Coordinación de Proyectos y Conversación

Sistema Integral de Gestión de Proyectos (Kanban), Conversación (Canales e Hilos), Gobernanza por Roles y Auditoría conectado en tiempo real a Google Sheets, Google Calendar y Gmail (`Code.gs`).

## Opciones de Despliegue 100% en la Nube (Independientes de tu equipo)

1. **100% en Google Drive / Google Apps Script (`Code.gs` + `Index.html`)**: Todo vive dentro de tu cuenta de Google, sin depender de servidores externos.
2. **GitHub Pages (`https://victornava55.github.io/unrc-gestion-proyectos/`)**: Alojamiento permanente gratuito desde este repositorio.
3. **Cloudflare Pages / Workers**: Conectando este repositorio `victornava55/unrc-gestion-proyectos` directamente a Cloudflare.
